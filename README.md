Webcam Game controller made for Touhou if you are crazy and want another way to play the game

## Binding

### Left hand bindings
#### Basic Movement
Binds left hand (tracks palm) to wasd

#### Focus
Binds left hand pointer/index raised to shift 

### Right hand bindings
#### Shoot
Binds right hand pointer/index raised to j 

#### Bomb
Binds right hand middle raised to k


## Running the program: 
First clone the repo

### How to run on windows 11

#### Setup
```powershell
python -m venv .venv

.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

#### Run the program
```powershell
python main.py
```
